# Engineering notes

These are the working documents behind SiKaya, kept for transparency and written mostly in Indonesian: [`AUDIT-SIKAYA.md`](AUDIT-SIKAYA.md) is the read-only audit of the original app that started the rewrite; [`ACCOUNTING-SPEC-SAK-EMKM.md`](ACCOUNTING-SPEC-SAK-EMKM.md) specifies the double-entry engine, the SAK EMKM report layouts and the scenarios the tests check; [`PLAN-FASE1.md`](PLAN-FASE1.md) is the phase-1 implementation plan; [`UI-PLAN.md`](UI-PLAN.md) defines the farmer-facing design rules (plain language, 48 dp touch targets, text up to 2.0x, contrast); [`UI-REVIEW.md`](UI-REVIEW.md) records the before/after visual review rounds done on an emulator, with [`UI-LAMA-NOTES.md`](UI-LAMA-NOTES.md) summarising the old UI it was compared against. They describe intent and process at the time they were written; the code and tests are the source of truth.
